# Transglobal Foodtech LLP website

Live site: https://www.transglobalfoodtech.com (served by GitHub Pages from `index.html` on `main`).

Staging: Google Sites copy at https://sites.google.com/osoeazy.com/transglobalfoodtech-staging/home (osoeazy.com accounts only).

Workflow: change staging first, review, then copy the approved code into `index.html` here. Every push to `main` publishes live.

The enquiry form posts to the live Google Form when the page is opened on transglobalfoodtech.com, and to the staging form anywhere else.
